# C Programming Practice & Study

A collection of C programming programs, practice exercises, and study notes covering fundamental concepts such as loops, conditionals, functions, and basic algorithms.

## Project Structure

- `basic-c/` - Core beginner exercises (conditionals, operators, conversions, basic calculators)
- `study/` - Study materials and notes
- Root directory - Additional practice programs (`factorial.c`, `whileloop.c`, `print 1 to 15.c`)

## Getting Started

### Prerequisites
- GCC compiler (e.g. MinGW-w64)

### Compile & Run
To compile and execute any program:
```powershell
gcc <filename>.c -o output/<filename>
./output/<filename>
```
